# tothegoal-app

Статические файлы Mini App «ДоЦели» для GitHub Pages. Репозиторий публичный: секретов здесь нет, и быть не должно.

- `dev/` — сборка для тестового бота (окружение dev).
- `legal/privacy.html` — политика конфиденциальности.

Файлы собираются командой `node web/publish.js` из основного (закрытого) репозитория и копируются сюда как есть, руками здесь ничего не правят.
